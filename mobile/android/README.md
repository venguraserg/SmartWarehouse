# «Склад» для Android

Приложение-оболочка: открывает веб-приложение склада с сервера предприятия и добавляет то, чего нет в браузере по http:

- **сканирование камерой** — кнопка 📷 внизу каждой страницы и на странице «Сканировать». Работает без https.
  Используется сканер Google (сервисы Google Play), отдельное разрешение на камеру не нужно;
- **встроенный сканер ТСД** — по умолчанию он «печатает» код как клавиатура, и это работает без настроек.
  Если сканер ТСД настроен на сообщения (Intent / Broadcast), выберите модель в настройках приложения:
  Zebra (DataWedge), Urovo / Chainway, Honeywell, Newland или «Другой» с действием и полем вручную;
- **PDF** (акты, наклейки) скачиваются в «Загрузки», открываются из уведомления;
- вход сохраняется между запусками; потянуть страницу вниз — обновить.

Код со сканера идёт тем же путём, что код ручного сканера в браузере: в выдаче, возврате и приходе добавляется строка,
на остальных страницах открывается ячейка или позиция.

Все экраны и логика — на сервере: новые функции появляются в приложении сами после обновления сервера.
Переустанавливать APK нужно только при изменениях в самой оболочке (эта папка).

## Где взять APK

Собирается в GitHub Actions (workflow **Android**) при изменениях в `mobile/android`:
- для `main` — в релизе **«Приложение для Android»** (`android-latest`) на странице Releases репозитория;
- для любой сборки — в разделе **Artifacts** запуска workflow.

Можно запустить сборку вручную: Actions → Android → Run workflow.

## Установка на телефон или ТСД

1. Скопируйте APK на устройство (USB, почта, мессенджер) и откройте его.
2. Разрешите установку из этого источника («Неизвестные источники»), если Android спросит.
3. При первом запуске укажите адрес сервера — тот, по которому сайт открывается в браузере, например `192.168.1.10:8081`.
   Телефон должен быть в сети предприятия (Wi-Fi).
4. Новая версия ставится поверх старой — настройки и вход сохраняются.

## Сканер ТСД через сообщения (если «как клавиатура» не подходит)

- **Zebra:** DataWedge → профиль для приложения «Склад» (com.smartwarehouse.app) → Keystroke output выключить,
  Intent output включить: action `com.smartwarehouse.SCAN`, delivery — Broadcast intent.
- **Urovo / Chainway:** настройки сканера → режим вывода «Broadcast / Intent»
  (action `android.intent.ACTION_DECODE_DATA`, поле `barcode_string`).
- **Honeywell:** Scanner settings → Data Intent включить (action `com.honeywell.decode.intent.action.EDIT_DATA`, поле `data`).
- **Другие:** найдите в настройках сканера action и имя поля с кодом и укажите их в «Другой».

## Сборка у себя

Нужны Android Studio (или Android SDK) и JDK 17: откройте папку `mobile/android` в Android Studio → Build → Build APK.

Ключ подписи `app/smartwarehouse.keystore` лежит в репозитории, чтобы все сборки были подписаны одинаково
и обновление ставилось поверх. Приложение внутреннее, репозиторий закрытый; для публикации в Google Play
ключ нужно заменить и хранить в секретах.
